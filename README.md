# sqa-automation-roadmap

> A structured 20-week self-paced learning plan to go from intermediate QA to career-ready automation engineer — specialising in **Playwright (JavaScript)** and **Selenium**.

---

## About

This repo is my personal learning journal for rebuilding and levelling up my QA automation skills. Each week has a focused topic, a concrete deliverable, and evaluation criteria. Progress is tracked in [`PROGRESS.md`](./PROGRESS.md).

**Primary tools:** Playwright (JavaScript) · Selenium (Java/Python)  
**Duration:** 20 weeks  
**Commitment:** ~2–3 hours/week  

---

## Roadmap Overview

| Phase | Weeks | Focus |
|-------|-------|-------|
| [Phase 1 — Foundations Reset](./phase-1-foundations/) | 1–4 | QA mindset, manual testing, JS basics, DOM & locators |
| [Phase 2 — Playwright Deep Dive](./phase-2-playwright/) | 5–8 | Setup, POM, API testing, CI/CD |
| [Phase 3 — Selenium Mastery](./phase-3-selenium/) | 9–12 | Setup, data-driven tests, advanced interactions, Grid |
| [Phase 4 — Framework Architecture](./phase-4-framework-architecture/) | 13–16 | Design patterns, API suites, perf/a11y, reporting |
| [Phase 5 — Career Ready](./phase-5-career-ready/) | 17–20 | Mobile strategy, OSS contribution, portfolio, mock interview |

---

## How This Works

1. Open the week file for the current week
2. Read through the **topics** — use the suggested resources or find your own
3. Complete the **deliverable** — commit your work to this repo or link to it
4. Review yourself against the **evaluation criteria**
5. Update [`PROGRESS.md`](./PROGRESS.md) — mark the week done and note reflections
